Политика обработки персональных данных

Бот «Знакомства» в MAX. С 18 августа 2026 г.

Соглашение · Тарифы · Продление

Если вы не согласны с политикой, прекратите использование бота.

Документ составлен по ФЗ № 152-ФЗ «О персональных данных».

1. Общие положения

Оператор обрабатывает данные пользователей бота «Знакомства» в мессенджере MAX: идентификатор, анкету, токен фото, лайки, блокировки, жалобы, чаты, служебные лимиты, телефон (если отправлен), технические сведения.

2. Цели обработки

  • предоставление функций сервиса знакомств;
  • модерация, жалобы, защита от спама;
  • техническая поддержка через бота;
  • учёт Премиум-подписки и оплат.

Отзыв согласия — через бота. Обработка прекращается в течение 10 рабочих дней.

3. Передача третьим лицам

Данные передаются API MAX (platform-api2.max.ru) и платёжному эквайеру при оплате. Оператор не продаёт персональные данные.

4. Права пользователя

Изменить анкету в боте, удалить аккаунт (/delete). Вопросы — через бота в MAX.

5. Споры

Обязательна претензия. Споры рассматриваются по месту нахождения оператора, право РФ.

6. Изменения

Оператор может обновлять политику. Актуальная версия публикуется на этой странице.
